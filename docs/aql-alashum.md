# عقل الأسهم

وضع شخصي للتحليل والتنبيهات بالعربية، دون تنفيذ صفقات أو الاتصال بحساب وسيط. يعمل من مدخل المشروع نفسه ويعيد استخدام قنوات التنبيه المهيأة. تظل واجهات الويب وأوامر البوت التفاعلية ومسار التحليل القديم كما هي؛ التقارير العربية الجديدة تخص وضع عقل الأسهم فقط.

## التشغيل

```bash
python main.py --aql --stocks NVDA,AMD --no-notify
AQL_MODE=adventurous python main.py --aql --no-notify
AQL_ENABLED=true python main.py --no-market-review
```

`--dry-run` يمنع إرسال الإشعارات ويولّد تقرير التحليل محليًا. لا يوجد في هذا الوضع تنفيذ أوامر أو شراء تلقائي، ولا يحتاج مفتاح نموذج ذكاء اصطناعي. التقارير تحفظ بترميز UTF-8 داخل `reports/aql_*.md`. الإشعارات نصية للحفاظ على العربية؛ البريد يعرض اتجاه الكتابة من اليمين لليسار. يمكن استخدام قنوات المشروع المهيأة مسبقًا. قوالب webhook التي كتبها المستخدم قد تحتوي نصوصه الخاصة.

الإعدادات: `AQL_ENABLED` (افتراضيًا false)، و`AQL_MODE` (افتراضيًا conservative)، و`AQL_STOCK_LIST`، و`AQL_ACCOUNT_JSON`. يستخدم `--stocks` بدل قائمة الوضع عند تحديده. القائمة الافتراضية: NVDA وMSFT وAAPL وAMD وGOOGL وMETA وAMZN وAVGO وPLTR وTSLA؛ تُرفض الرموز الأخرى بدل إدخال أسهم غير متحققة من السوق المستهدف. القائمة منتقاة للتكنولوجيا والذكاء الاصطناعي وليست مسحًا شاملًا لناسداك، وتحتاج مراجعة دورية لتغير الإدراج.

لا يدعم هذا الوضع `--schedule` أو الخدمة أو مراجعة السوق وحدها أو استيراد محفظة الوسيط أو الباكتيست أو أوضاع ETF؛ تُرفض تلك التركيبات صراحة. استخدم مجدولًا خارجيًا لتكرار أمر التحليل الفردي.

## قواعد التحليل

- المصدر Yahoo Finance عبر yfinance، شموع 15 دقيقة بتوقيت افتتاح الشمعة، جلسة التداول العادية فقط. لا يوجد بديل يومي عند تعطل البيانات.
- لا تحتسب شمعة حتى تمر 15 دقيقة كاملة من بدايتها. يلزم آخر إغلاق متاح، وتسلسل مكتمل لآخر 21 شمعة؛ لا تكفي قمة لحظية فوق المقاومة.
- تقويم XNYS يحدد أيام التداول وساعات الجلسة والعطل والإغلاق المبكر، مع توقيت نيويورك والتوقيت الصيفي. فشل التقويم يمنع الدخول. الجلسات العادية للأسهم المختارة توافق هذا التقويم.
- متوسط السعر المرجح بالحجم (VWAP): مجموع السعر النموذجي `(أعلى + أدنى + إغلاق) / 3` مضروبًا في الحجم، مقسومًا على إجمالي الحجم، من بداية الجلسة حتى آخر شمعة مغلقة.
- الحجم النسبي: حجم شمعة التأكيد / متوسط حجم الفترة نفسها في آخر خمس جلسات تداول. نقص أي فترة مرجعية يمنع الدخول.
- الزخم: تغير الإغلاق مقارنة بأربع شموع سابقة (ساعة). يلزم خمس شموع مغلقة من الجلسة الحالية، لذلك أول تقييم ممكن بعد 10:45 بتوقيت نيويورك.
- المقاومة: أعلى سعر في آخر 20 شمعة مغلقة قبل شمعة التأكيد. الدعم/وقف الخسارة: أدنى سعر في آخر أربع شموع سابقة. يلزم إغلاق أعلى من المقاومة وأعلى من VWAP، مع حجم وزخم مناسبين.

## لقطة الحساب وإدارة المخاطر

لا يُفترض رصيد افتراضي. ضع لقطة حساب حديثة في متغير `AQL_ACCOUNT_JSON`، ولا تودع بياناتك الشخصية في المستودع:

```json
{"equity":10000,"start_equity":10000,"cash":10000,"open_risk":0,"daily_loss":0,"as_of":"2026-11-06T16:00:00+00:00"}
```

القيم بالدولار: `equity` صافي قيمة الحساب الحالي شامل الربح والخسارة غير المحققة؛ `start_equity` قيمته عند بداية يوم التداول الأمريكي؛ `cash` السيولة المتاحة دون اقتراض؛ `daily_loss` مجموع خسائر الصفقات الخاسرة المحققة خلال اليوم والخسائر غير المحققة للمراكز الخاسرة دون خصم أرباح الصفقات الأخرى (لا يُخفض بعد بلوغ حد اليوم)؛ `open_risk` الخسارة الإضافية المحتملة من الأسعار الحالية حتى الوقف لجميع المراكز والأوامر القائمة؛ `as_of` وقت التحقق من اللقطة مع المنطقة الزمنية، في اليوم نفسه وألا يتجاوز عمرها خمس دقائق. المثال تاريخي ويمنع الدخول إذا استُخدم كما هو في وقت آخر.

حد الصفقة 2% من القيمة الحالية. حد اليوم 2% من قيمة بداية اليوم. يُحسب المتبقي بعد طرح الأكبر من خسارة اليوم غير المعوضة بالأرباح وتراجع قيمة الحساب عن بداية اليوم والمخاطرة المفتوحة؛ الأرباح لا ترفع سقف اليوم. حجم الصفقة عدد صحيح يُقرب للأسفل، ويُقيد بالسيولة والمتبقي من حد اليوم. لذلك يمكن أن تقل المخاطرة الفعلية عن 2%، ولا يجوز تخصيص 2% كاملة لكل سهم في سلة واحدة.

تقريب الدخول للأعلى والوقف للأسفل إلى سنت، ثم الهدف الأول عند ضعف مسافة الوقف والثاني عند ثلاثة أضعافها. هذه أهداف حسابية وليست تقديرًا لاحتمال الوصول؛ نسبة العائد إلى المخاطرة قبل الرسوم 2:1 و3:1. الرسوم والفجوات والانزلاق قد تجعل الخسارة الفعلية أكبر؛ لا توجد حماية فعلية لحساب وسيط في هذا الوضع.

يحجز التقرير مخاطرة وسيولة كل إشارة قبل تقييم التالية. عند تكرار التشغيل يجب تحديث اللقطة لتشمل المراكز والأوامر التي قرر المستخدم تنفيذها؛ التقارير ليست أوامر ولا سجلاً مشتركًا لحجز الأموال بين عمليات متزامنة. لا تُنفّذ كل تقارير متكررة كأنها ميزانيات مستقلة.

عند غياب البيانات أو قدمها أو بلوغ الحد اليومي يعرض التقرير سبب منع الدخول، دون عرض خطة دخول أو أهداف أو حجم غير موثوق. يظل التحليل السوقي متاحًا عند غياب بيانات الحساب.

## GitHub Actions

لم تتغير المواعيد أو الأسرار القديمة أو المدخلات أو صلاحيات العمل أو خطوات البناء. أضيفت أربعة متغيرات اختيارية فقط إلى خطوة التحليل:

1. ضع Repository Variable باسم `AQL_ENABLED=true` لتفعيل الوضع، و`AQL_MODE=conservative` أو `adventurous`، و`AQL_STOCK_LIST` اختياريًا.
2. ضع `AQL_ACCOUNT_JSON` كـ Actions Secret إن أردت خطط دخول، وحدّثه قبل التشغيل بلقطة حديثة. لا يلزم لتقارير المراقبة.
3. شغّل workflow يدويًا بوضع `stocks-only` أو `full` أثناء الجلسة. `market-only` غير مدعوم في هذا الوضع.

الجدول الحالي 10:00 UTC يقع قبل الجلسة الأمريكية؛ أبقيناه كما طلبت، ولذلك تشغيله في ذلك الوقت ينتج مراقبة بلا توصية دخول. GitHub Actions ليس مصدر أسعار حيًا ولا مجدولًا مضمونًا كل 15 دقيقة. استخدام مجدول خارجي أثناء الجلسة وتحقيق حداثة اللقطة مسؤولية التشغيل؛ لم يتم تفعيل التشغيل الفعلي أو تعديل إعدادات حساب GitHub الخارجية.
